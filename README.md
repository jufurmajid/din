# دفتر ديون إلكتروني

تطبيق أندرويد بسيط يعمل بدون إنترنت لإدارة الديون والمدفوعات.

## الوظائف
- إضافة اسم الشخص ومبلغ الدين.
- تسجيل تاريخ الدين.
- إضافة ملاحظة.
- عرض جميع الديون.
- معرفة إجمالي الديون غير المسددة.
- فتح تفاصيل أي دين.
- تسجيل تاريخ التسديد تلقائياً.
- حذف الدين.
- يعمل بدون إنترنت.

اسم المستودع: din
