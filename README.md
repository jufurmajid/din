# بلشر كوزمتك

تطبيق أندرويد عربي لمتجر **بلشر كوزمتك**.

## الموجود حالياً
- واجهة RTL عربية.
- الصفحة الرئيسية للمتجر.
- بحث عن المنتجات.
- تصنيفات المنتجات.
- بطاقات المنتجات وتفاصيل المنتج.
- إضافة وإنقاص المنتجات في السلة.
- حساب إجمالي السلة.
- تصميم وردي مناسب لمتجر مستحضرات التجميل.
- لا يحتاج اتصالاً بالإنترنت للوظائف الأساسية الحالية.
- اسم التطبيق الظاهر: بلشر كوزمتك.

ملف التصميم المرجعي موجود في جذر المستودع باسم `design.png`.

> ملاحظة: صور المنتجات الحقيقية وربط الطلبات/بيانات المتجر يمكن إضافتها في المرحلة التالية.
