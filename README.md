# دفتر ديون إلكتروني

تطبيق أندرويد بسيط يعمل بدون إنترنت لإدارة الديون والمدفوعات.

## الوظائف
- إضافة اسم الشخص ومبلغ الدين.
- تسجيل تاريخ الدين والملاحظة.
- عرض جميع الديون وإجمالي الديون غير المسددة.
- تسجيل تاريخ التسديد.
- حذف الدين.
- تصدير دين واحد كصورة ومشاركته.
- تصدير دفتر الديون كاملًا كصورة.
- حفظ نسخة احتياطية تلقائية في ملف على الجهاز داخل مجلد Downloads/DebtBook.
- استعادة الديون من ملف النسخة الاحتياطية.
- ملف النسخة الاحتياطية يبقى في مساحة ملفات الجهاز المشتركة حتى بعد حذف التطبيق، ويمكن نقله إلى جهاز آخر واستعادته.

اسم المستودع: din
